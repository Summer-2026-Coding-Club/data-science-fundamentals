# Extra Resources

Optional — use these if you want more practice, a different explanation, or to go further after the walkthrough.

- [Pandas official "10 minutes to pandas"](https://pandas.pydata.org/docs/user_guide/10min.html): quick, official tour of the core pandas operations.
- [NumPy quickstart](https://numpy.org/doc/stable/user/quickstart.html): the basics of arrays straight from the docs.
- [Kaggle: Pandas course](https://www.kaggle.com/learn/pandas): free, short, interactive lessons with exercises.
- [Kaggle Datasets](https://www.kaggle.com/datasets):  free real-world datasets if you want to practice on something you find interesting.
- [Matplotlib tutorials](https://matplotlib.org/stable/tutorials/index.html): for fancier charts than what's in the walkthrough.
- [Google Colab](https://colab.research.google.com/):  run notebooks in your browser, no install needed, and these libraries come pre-installed.
