# data-science-fundamentals

Supplementary material for working with data in Python: NumPy arrays, pandas DataFrames, and basic plotting. Learning data science techniques.

## How this repo is organized

- [`00_setup.md`](00_setup.md): install NumPy, pandas, matplotlib, and Jupyter. (This is the first step!)
- [`01_numpy_and_pandas_basics.ipynb`](01_numpy_and_pandas_basics.ipynb): NumPy arrays, building and exploring DataFrames, filtering, sorting, grouping, and a first plot, with exercises along the way.
- [`02_data_cleaning.ipynb`](02_data_cleaning.ipynb): handling missing values, removing duplicate rows, and fixing column types (strings that should be numbers or dates), with exercises along the way.
- [`RESOURCES.md`](RESOURCES.md): extra outside resources if you want more practice or a different explanation of something.

## About the exercises

Exercises in notebooks are **open-ended**: try these on yourself first!

If you are stuck or want to check your work, solutions live on a separate `solutions` branch on git.

## What's coming next

Coming up:

- **Data Visualization** : histograms and boxplots for distributions, scatter plots for relationships between two variables, bar/line charts for comparisons over categories or time.
- **Summarizing with Statistics**: summarizing a column, comparing distributions, correlation vs. causation.
- **Regression Models**: linear regression (fitting a line to predict a continuous value and interpreting coefficients).
- **Classification Models**: predicting a binary and multiclass outcome, using metrics like accuracy/precision/recall.
- **A real Kaggle dataset, start to finish**: clean it, explore it, fit a model, write up what you found.

After that, see [`machine-learning-fundamentals`](../machine-learning-fundamentals/README.md) for the next step up.
